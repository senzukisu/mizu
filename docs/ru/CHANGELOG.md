# Изменения

Здесь описаны все заметные изменения Mizu. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## [0.1.2] — 2026-11-11

### Исправлено
- Вкладки больше не дёргаются, когда сайт то включает, то выключает звук. Значок звука держится ещё немного после
  того, как звук стих, и плавно появляется и исчезает.

### Добавлено
- **«Выгрузить вкладку»** и **«Выгрузить остальные вкладки»** в контекстном меню вкладки. Страница закрывается и
  освобождает память, вкладка остаётся и загрузится снова при открытии. Вкладки со звуком не выгружаются.
- Руководство пользователя с таблицей решения проблем: [GUIDE.md](GUIDE.md).

## [0.1.1] — 2026-11-11

### Исправлено
- **Mizu больше не зависает при большом количестве вкладок.** Веб-представления теперь встраиваются визуально (DirectComposition):
  - внутри окна Mizu больше нет окон движка, поэтому занятый движок не может заблокировать интерфейс;
  - открытие, закрытие и переключение вкладок остаются плавными, пока страницы грузятся.
- При запуске скрытое окно могло зациклиться на фокусе и подвешивать Проводник.
- Полоса вкладок больше не дёргается у минимальной ширины. При большом количестве вкладок она прокручивается вбок (колёсиком или тачпадом) и плавно затухает по краям.
- Кнопка «картинка в картинке» теперь появляется на YouTube и других сайтах с Trusted Types.
- Изменение масштаба страниц по умолчанию теперь применяется к открытым вкладкам.
- Подсказки адресной строки занимают всю её ширину.

### Добавлено
- **Настройка сочетаний клавиш** в «Настройки» → «Сочетания клавиш». Любое действие можно перезаписать или сбросить, конфликты разрешаются автоматически.
- **Поисковые подсказки** выбранной поисковой системы (DuckDuckGo, Google, Bing, Brave, Ecosia, Яндекс, Википедия). Есть отдельный переключатель, в приватных окнах подсказки не используются.
- Картинка в картинке:
  - кнопки «предыдущее/следующее видео» и перемотка на 10 секунд в плавающем окне;
  - настройки положения кнопки и компактная кнопка (только значок).
- «Настройки» → «Основные» → «Обновления»: кнопки «Проверить обновления» и «Обновить». Найдя новую версию при запуске, Mizu спрашивает перед установкой.
- Контекстное меню на панели закладок (открыть в новой вкладке, окне или приватном окне; копировать ссылку; удалить). Панель появляется, только когда на ней есть закладки.
- «Открыть менеджер паролей» в «Настройки» → «Безопасность» и увеличенное окно подтверждения закрытия.
- Установщик и удаление в стиле Mizu с выбором папки установки.

## [0.1.0] — 2026-11-10

Первый публичный выпуск.

### Установка и обновление
- `MizuSetup` ставит Mizu для текущего пользователя, права администратора не нужны.
  - Окно установки в стиле Mizu, папку можно выбрать (по умолчанию `%LOCALAPPDATA%\Programs\Mizu`).
  - Ярлыки в меню «Пуск» и, по желанию, на рабочем столе; регистрация в «Приложениях по умолчанию».
  - Удаление в том же стиле, по желанию вместе с данными. Удаляются только файлы, которые поставил установщик.
- Есть альтернатива — портативный zip.
- Автообновление:
  - Mizu проверяет GitHub через 90 секунд после запуска, затем каждые 6 часов;
  - манифест выпуска подписан ed25519, SHA-256 установщика сверяется до того, как появится «Перезапустить и обновить»;
  - обновление ставится без вопросов, после чего Mizu перезапускается.
- Окно по умолчанию открывается развёрнутым.

### Движок
- Microsoft Edge WebView2 (Chromium) с песочницей Chromium и изоляцией сайтов. Среду выполнения обновляет Windows.
- Одно дерево процессов на профиль, отдельный профиль в памяти для приватных окон.
- Внутренняя схема `mizu://` отдаёт файлы, вшитые в программу, со строгой политикой CSP.

### Интерфейс
- Собственное окно без рамки: вкладки в заголовке, Mica в Windows 11, системные границы изменения размера.
- **Вертикальные вкладки:**
  - боковая панель меняет ширину перетаскиванием края (двойной щелчок возвращает исходную);
  - сворачивается до значков;
  - кнопка «Новая вкладка» находится под последней вкладкой.
- Вкладки:
  - создание, закрытие, перетаскивание, закрепление, дублирование, отключение звука, повторное открытие закрытых (хранятся последние 25);
  - контекстное меню и сочетания клавиш;
  - плавные FLIP-анимации;
  - новые вкладки открываются мгновенно из заранее созданного окна.
- Адресная строка:
  - сама понимает, адрес это или поисковый запрос;
  - подсказывает из истории, закладок и внутренних страниц;
  - поддерживает поисковые системы по `@ключевому слову`;
  - показывает значок безопасности, счётчик Shield, ключ паролей, звезду закладки и масштаб.
- Новая вкладка: плитки закладок, плитка «+» и переключатель поисковой системы.
- Темы:
  - светлая, тёмная или как в системе;
  - пять палитр и любой акцентный цвет;
  - плотность, мягкий или чёткий стиль, переключатель анимаций.
- Внутренние страницы не мигают: тема применяется до первой отрисовки.
- **Русский перевод** всего интерфейса. Язык берётся из Windows или задаётся в настройках.
- Внутренние страницы: новая вкладка, настройки, история, закладки, загрузки, пароли, Mizu Shield, скрипты и
  расширения, диагностика медиа, «О Mizu», страница блокировки.

### Приватность и безопасность
- **Mizu Shield** — блокировка на adblock-rust:
  - синтаксис uBlock Origin / Adblock Plus, косметические фильтры и скриптлеты;
  - стандартные подписки: uBlock filters, Privacy, Unbreak, Badware, EasyList, EasyPrivacy, Peter Lowe;
  - дополнительные: Annoyances, EasyList Cookie;
  - свои списки и правила, исключения для сайтов, блокировка целых страниц с предупреждением;
  - загрузка списков через зеркала и с повторами.
- **Пароли Mizu:**
  - шифрование Windows DPAPI;
  - аккуратное окно «Сохранить пароль?» после входа и заполнение из адресной строки;
  - страница управления с поиском, показом, копированием и редактированием;
  - импорт и экспорт CSV (Chrome, Edge, Firefox, Bitwarden) и список сайтов «никогда не сохранять».
- Уровни защиты от отслеживания движка, Global Privacy Control (заголовок `Sec-GPC` и `navigator.globalPrivacyControl`).
- Разрешения сайтов: запрос и запоминание решений. Приватные окна решений не сохраняют.
- Очистка данных по категориям и периоду, очистка при выходе.
- Всплывающие окна без действия пользователя блокируются, опасные внешние протоколы запрещены.
- Никакой телеметрии.

### Медиа
- Встроенная **картинка в картинке**: кнопка при наведении на видео и сочетание Alt+Shift+P.
- `mizu://media` показывает кодеки, системные декодеры и аппаратное ускорение.

### Данные
- Профиль хранится в SQLite: миграции, журнал WAL, автоматическая резервная копия и восстановление при повреждении.
- Сеанс сохраняется периодически и при выходе. После сбоя Mizu предлагает восстановить вкладки, а восстановленные
  вкладки загружаются по требованию.
- История, закладки (папки, панель, перетаскивание), загрузки, разрешения сайтов.
- Настройки — в читаемом TOML с проверкой. Повреждённый файл откладывается в сторону.

### Загрузки
- Собственный менеджер загрузок вместо интерфейса движка:
  - прогресс, скорость, оставшееся время;
  - пауза, продолжение, отмена, повтор, открыть, показать в папке;
  - выбор папки и вопрос «куда сохранить».

### Скрипты и расширения
- **Mizu Scripts** — менеджер скриптов, совместимый с Greasemonkey/Tampermonkey:
  - `@match`, `@include`, `@exclude`, `@require`, `@run-at`;
  - API `GM_*` / `GM.*`, хранилище каждого скрипта защищено токеном страницы;
  - установка по ссылкам с Greasy Fork, Sleazy Fork, OpenUserJS, GitHub (с зеркалом jsDelivr), Gist, GitLab, Codeberg и Bitbucket;
  - несколько ссылок или файлов сразу, с выбором скриптов;
  - ежедневное автообновление через `@updateURL` и `@downloadURL`;
  - правила сайтов для каждого скрипта: только на выбранных сайтах или никогда на некоторых.
- Расширения Chromium MV3:
  - «Добавить в Mizu» в один щелчок на странице Chrome Web Store или вставкой ссылки;
  - установка из `.crx`, `.zip` или папки;
  - включение, отключение, удаление, параметры.

### Производительность
- Запуск быстрее чем за полсекунды на обычном ПК. Окно появляется, только когда интерфейс готов.
- Общие настройки движка применяются один раз, представления закрываются в фоне, режим экономии памяти включается после
  2 минут простоя.
- Интерфейс перерисовывается не чаще раза за кадр, прогресс загрузок обновляется около 4 раз в секунду, панель закладок кешируется.
- Спящие вкладки (задержка настраивается), режим эффективности, переключатель аппаратного ускорения.

### Известные ограничения
- Восстановленные вкладки помнят адрес, но не историю «назад/вперёд»: движок её не отдаёт.
- `GM_xmlhttpRequest` подчиняется CORS, у `GM_registerMenuCommand` пока нет меню.
- Общие косметические фильтры (по class/id) не применяются, фильтры для конкретных сайтов работают.
- У расширений нет кнопок на панели: параметры и всплывающие окна открываются во вкладке. В приватных окнах расширений нет.
- Установка из Microsoft Edge Add-ons пока ненадёжна; Chrome Web Store работает.
- Только Windows.
