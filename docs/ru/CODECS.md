# Видео, звук и кодеки

Mizu воспроизводит медиа через медиаконвейер Chromium в движке WebView2. **Mizu не поставляет собственных кодеков.**
`mizu://media` показывает реальное состояние компьютера, на котором он запущен.

## Что поддерживается

| Формат | Источник | Примечания |
|---|---|---|
| H.264 / AVC | Движок (лицензия Microsoft в Edge WebView2) | Аппаратное декодирование через D3D11/DXVA, если его поддерживает видеокарта |
| AAC | Движок (лицензирован) | |
| VP8, VP9 | Движок | VP9 аппаратно декодируют большинство видеокарт примерно с 2016 года |
| AV1 | Движок (dav1d) и система | Аппаратно на новых видеокартах (например, RTX 30/40, Intel Xe, Radeon RX 6000+), иначе программно |
| Opus, Vorbis, FLAC, MP3, PCM | Движок | |
| H.265 / HEVC | **Система**: нужен декодер видеокарты **и** «Расширения для видео HEVC» из Microsoft Store | Программно внутри движка недоступен |
| AC-3, E-AC-3 | Система (декодеры Dolby есть в некоторых редакциях Windows и образах производителей) | Наличие зависит от системы |
| ALAC | Поддержка движка и системы различается | |
| MPEG-4 Part 2, MPEG-2, Theora | Chromium не воспроизводит их на сайтах | Показываются как «Нет», даже если в Windows есть декодеры |

Контейнеры, которые могут использовать сайты: MP4, WebM, Ogg, WAV, FLAC, MPEG-TS (через Media Source Extensions с
подходящими кодеками). Matroska (MKV) работает, если внутри поддерживаемые кодеки. QuickTime и AVI как файлы обычно не
воспроизводятся.

## Аппаратное ускорение

Движок сам выбирает аппаратное или программное декодирование для каждого потока. Задача Mizu — держать ускорение
включённым («Настройки» → «Производительность» → «Аппаратное ускорение», включено по умолчанию) и показывать результат:
`mizu://media` сообщает флаг `powerEfficient` из API MediaCapabilities, который соответствует аппаратному декодированию.

Если видео подтормаживает или сильно грузит процессор:
1. Откройте `mizu://media` и проверьте, что у кодека стоит **«Аппаратно»**.
2. Обновите драйвер видеокарты.
3. Для HEVC установите «Расширения для видео HEVC».
4. В крайнем случае выключите аппаратное ускорение (с некоторыми неисправными драйверами так лучше) и перезапустите Mizu.

Автовоспроизведение можно ограничить в «Настройки» → «Медиа»; изменение действует после перезапуска.

## Картинка в картинке

Когда вы наводите курсор на видео, Mizu показывает маленькую кнопку «PiP», а Alt+Shift+P выносит играющее видео в
отдельное окно. Mizu использует стандартный Picture-in-Picture API движка, поэтому это работает и на сайтах, которые
прячут свою кнопку. Кнопку можно выключить в «Настройки» → «Медиа».

## Лицензии

- H.264 и AAC покрываются лицензиями Microsoft на среду Edge WebView2. Её устанавливает и обновляет Windows, а не Mizu.
- HEVC, AC-3 и E-AC-3 используются только через декодеры, уже установленные в системе пользователя.
- Mizu намеренно не встраивает FFmpeg или GStreamer: это потребовало бы патентных решений по каждому кодеку и не нужно,
  пока декодирование дают движок и ОС. Если Mizu перейдёт на CEF (см. план развития), лицензирование кодеков будет
  оценено до того, как в сборку попадёт любой проприетарный кодек.
