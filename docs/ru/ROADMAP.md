# План развития Mizu

Куда движется Mizu после серии 0.1. Версии упорядочены по тому, что важнее всего в ежедневном использовании, затем
по техническим зависимостям. Дат нет: версия выходит, когда выполнены её условия готовности.

**Принципы:** стабильность → безопасность → производительность → сопровождаемость → расширяемость. Новая
возможность никогда не ухудшает первые три.

**Где мы сейчас:** вышла 0.4.1 с защитой от отпечатков. Дальше: отчёт об отпечатках и строгий режим (0.4.2), затем
зашифрованные копии; из 0.3.x ещё открыты интеграционные тесты и подписанный установщик.
Что уже вышло, по версиям, — в [списке изменений](CHANGELOG.md).

Идеи и пожелания — в [issues](https://github.com/senzukisu/mizu/issues).

## Уже есть в 0.1.x

- **Установка и обновление:** подписанные автообновления; установщик и удаление с выбором папки.
- **Скорость:** визуальное встраивание, поэтому Mizu не зависает с множеством вкладок; спящие и выгружаемые вкладки.
- **Вкладки:** вертикальные вкладки с панелью в одну строку.
- **Возможности:**
  - Mizu Shield;
  - менеджер паролей;
  - скрипты с правилами сайтов;
  - расширения Chrome;
  - настраиваемые сочетания клавиш;
  - поисковые подсказки;
  - «картинка в картинке» с переключением видео.
- **Язык:** интерфейс и документация на русском и английском.

## 0.2 — «Чистая вода» ✅

Вышла 15.11.2026. Что в ней появилось (подробно — в [списке изменений](CHANGELOG.md)):

- **Куки:** сессионные куки переживают перезапуск, сторонние куки блокируются по умолчанию, куки сайта видны в значке
  замка, есть «Очистить данные сайта».
- **Ссылки в программы** (`steam:`, `tg:`, `zoom:`, `mailto:`…) с вопросом, «разрешать всегда» для сайта и списком в
  настройках.
- **Поиск на странице** в собственной панели Mizu.
- **Закреплённые вкладки сбоку** — сетка иконок с перетаскиванием; закреплённая вкладка помнит свою страницу.
- **Адресная строка:** калькулятор, «перейти на вкладку»; адрес обновляется в том же кадре, что и вкладка.
- **Новая вкладка:** свои ярлыки (отдельно от панели закладок), перетаскивание, фоны, панель «Настроить».
- **Поиск по настройкам**, кнопка перезапуска, спокойные карточки; **загрузки** по дням со значками типов файлов;
  обновлённая страница **«О Mizu»** с «Что нового».

Перенесено в 0.3: импорт из других браузеров, косметические фильтры Shield и страница сайта, поставщик UI
Automation, ускорение загрузки, «Открыть с помощью…», автоочистка куки, CI, откат обновлений и бета-канал, отчёты о
сбоях.

## 0.4 — «Глубокая вода»: приватность и данные

**Цель:** сильнее защита, а сайты при этом не ломаются; ваши данные в безопасности, даже если с этим ПК что-то
случится.

Выходит по шагам, каждый полезен сам по себе:

| Шаг | Что вы получите | Как это работает |
|---|---|---|
| **0.4.0 ✅** | **«Сначала HTTPS»** · панель Shield v2 | Переходы верхнего уровня на `http://` сначала пробуются как `https://` (если не вышло — понятная страница «у сайта нет защищённой версии, продолжить?», выбор запоминается для сайта). Страница Shield получает разбивку по сайтам и хронологию из счётчиков, которые Mizu уже ведёт. |
| **0.4.1 ✅** | **Защита от отпечатков** (обычная) | Скрипт в начале документа отдаёт API с высокой энтропией защитные значения: небольшой шум для чтения canvas и звука — свой для сайта и сеанса, округлённые `hardwareConcurrency`/`deviceMemory`, без API батареи, общий список шрифтов. Выключается для сайта через значок замка. |
| **0.4.2** | Отчёт об отпечатках · строгий режим | Shield показывает, какие скрипты на странице читают какие API. Строгий режим ещё и скрывает детали WebGL и точный размер экрана. |
| **0.4.3** | **Зашифрованная резервная копия и восстановление** | Один файл с закладками, историей, паролями, настройками, скриптами и плитками; ключ из пароля через Argon2id, шифрование XChaCha20-Poly1305 (крейты RustCrypto, без самодельной криптографии). Восстановление сначала проверяет целостность и никогда не применяется наполовину. По желанию — копия по расписанию в выбранную папку. |

**Правила**

- У каждой защиты есть исключение для сайта в «Настройках сайта» и короткая пометка «что это может сломать».
- Никаких обещаний анонимности: руководство прямо пишет, что защита от отпечатков умеет и чего не умеет.
- Новые настройки появляются на уже существующих страницах (Mizu Shield, Конфиденциальность, Пароли и безопасность);
  ничего нового не включается по умолчанию, пока не пройдёт список сайтов ниже.

**Список «ничего не сломалось»:** вход Google и Microsoft, YouTube, Twitch, Discord, GitHub, Figma, Notion,
два банка, два магазина с 3-D Secure, проверки Cloudflare и hCaptcha.

**Готово, когда:**
- список сайтов работает с «Сначала HTTPS» и обычной защитой от отпечатков;
- шум постоянен внутри сайта и сеанса и разный на разных сайтах (проверяется тестовой страницей);
- копия побитно восстанавливается в чистый профиль, а неверный пароль или повреждённый файл отклоняются с понятным
  сообщением.

## 0.5 — «Прилив»: пароли и синхронизация

**Цель:** ваши данные на всех устройствах, и прочитать их можете только вы.

- **Пароли v2:**
  - Windows Hello перед показом или заполнением пароля;
  - генератор паролей;
  - проверка утечек с k-анонимностью (с устройства уходят только префиксы хешей);
  - ключи доступа (passkeys), где их поддерживает движок.
- **Mizu Sync (по желанию):** синхронизация закладок, истории, вкладок, настроек и паролей со сквозным шифрованием.
  Сервер хранит только шифротекст, его можно развернуть у себя.

**Готово, когда:** независимый аудит паролей и синхронизации не оставил открытых серьёзных замечаний.

## 0.6 — «Эстуарий»: встроенные инструменты

- **Просмотр PDF** с панелью Mizu: пометки, формы и печать.
- **Перевод** локальной моделью, где позволяет железо. Облачный сервис — только с явного согласия.
- **Режим чтения** с типографикой Mizu.
- **Кнопки расширений** и их всплывающие окна на панели, когда движок даст такую возможность.
- **Экранные дикторы** (перенесено сюда из 0.3.x): собственный поставщик UI Automation, чтобы NVDA и Экранный
  диктор читали визуально встроенные страницы и интерфейс, плюс полное управление боковой панелью и панелями с
  клавиатуры. Готово, когда NVDA и Экранный диктор читают страницы, меню и панели.

## 0.7 — «Реки»: Linux, macOS и мобильные устройства

WebView2 есть только в Windows, поэтому на каждой платформе свой движок за интерфейсом `mizu-engine`:

| Платформа | Движок | Примечания |
|---|---|---|
| macOS | WKWebView | H.264/AAC от системы; Shield через правила WebKit плюс косметический слой и скриптлеты Mizu |
| Linux | WebKitGTK (или CEF) | WebKitGTK есть в дистрибутивах; CEF — только если там понадобятся расширения |
| Android | Android System WebView | Мобильная раскладка вокруг того же HTML-интерфейса |
| iOS / iPadOS | WKWebView | Apple требует WebKit на iOS (вне ЕС) |

- **Уже переносимо:** интерфейс (`assets/ui`), хранилище, настройки, движок фильтров Shield, скрипты и модель вкладок.
  Пароли переходят на связку ключей платформы вместо DPAPI.
- **Зависит от платформы:** адаптер движка, окна и ввод, установщик и обновления.
- **Мобильная раскладка:** адресная строка снизу, сетка вкладок и жесты; настройки и возможности общие с десктопом.
- **Расширения** остаются прежде всего для Windows. На платформах с WebKit основные потребности закрывают скрипты и
  Shield.

**Готово, когда:** основные возможности работают на каждой платформе; это отслеживается в таблице совместимости в
[Архитектуре](ARCHITECTURE.md).

## 1.0 — «Океан»: стабильная версия

- Не меньше 99,8% сеансов без сбоев (по добровольной локальной статистике) и ни одной известной ошибки с потерей
  данных.
- Пройден аудит доступности: только клавиатура, экранные дикторы, высокий контраст.
- Задокументированная и версионированная совместимость расширений и скриптов.
- Долгосрочная стратегия движка (WebView2, CEF или Servo) с планом перехода.

## Идеи на рассмотрении

| Идея | Решение |
|---|---|
| Движок Servo | Следим. Перспективный движок на Rust, но для обычных сайтов пока не готов. Пересматриваем каждый выпуск. |
| ИИ-функции | Только необязательные и прежде всего локальные (пересказ, перевод). Никогда не включены по умолчанию, и содержимое страниц не уходит с устройства втихую. |
| Больше языков интерфейса | Да. Перевод — это один файл-словарь, помощь приветствуется. |
| Дополнения Firefox | Не на WebView2: он запускает только расширения Chromium. Вернёмся к этому, если их поддержит будущий движок. |
| Встроенный криптокошелёк | Нет. Это вне задач браузера и расширяет поверхность атаки. |
