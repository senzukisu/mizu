# План развития Mizu

Это план Onibi Lab для Mizu после серии 0.1. Пункты упорядочены по пользе для пользователей и по техническим
зависимостям. Каждый пункт реализуем на выбранной архитектуре; то, что зависит от будущего движка, отмечено. Дат
нет намеренно: версия выходит, когда выполнены её условия готовности.

**Принципы:** стабильность → безопасность → производительность → сопровождаемость → расширяемость.
Новые возможности никогда не ухудшают первые три.

## 0.2.0 — «Чистая вода»: доводка и доверие

Цель — чтобы Mizu хотелось оставить браузером по умолчанию.

Уже вышло в 0.1.x:
- подписанные автообновления и установщик с выбором папки;
- визуальное встраивание, благодаря которому Mizu не зависает с множеством вкладок;
- вертикальные вкладки с панелью в одну строку и выгрузка вкладок;
- менеджер паролей, правила сайтов для скриптов и настраиваемые сочетания клавиш;
- поисковые подсказки, «картинка в картинке» с переключением видео и русский перевод.

**Возможности**
- Надёжнее обновления: откат, если новая версия не запускается, разностные обновления, канал «бета».
- Установщик с подписью Authenticode и пакет MSIX для Microsoft Store.
- Панель поиска по странице в интерфейсе Mizu (Find API движка).
- Папки на панели закладок раскрываются меню; страницу можно перетащить на панель за значок замка.
- Общие косметические фильтры (селекторы class/id через лёгкий наблюдатель DOM) и процедурные косметические фильтры.
- Страница настроек сайта: масштаб, разрешения, Shield, cookies.
- Режим «сначала HTTPS»: адреса `http://` повышаются до HTTPS, а если сайт работает только по HTTP, показывается предупреждение.

**Технические работы**
- Интеграционные тесты, управляющие настоящим интерфейсом (протокол DevTools WebView2), и проверка JS в CI.
- Локальные отчёты о сбоях (минидампы в профиле, отправка только по желанию).
- Профилирование запуска: цель — меньше 400 мс до первой отрисовки на среднем ноутбуке.

**Зависит от:** 0.1.0.

**Готово, когда:**
- обновление выдерживает намеренные сбои: неверная подпись, прерванная загрузка, неудачный запуск;
- установщик проходит Windows App Certification;
- неделя ежедневного использования проходит без сбоев.

## 0.3.0 — «Течения»: пространства и фокус

**Возможности**
- **Пространства Mizu (Spaces):** именованные наборы вкладок («Работа», «Учёба», «Отдых») со своим цветом и значком.
  Переключаются с полосы вкладок, каждое восстанавливается отдельно.
- **Дерево вкладок** в боковой панели: вкладки, открытые со страницы, группируются под ней.
- **Группы вкладок** в горизонтальной полосе: сворачивание, цвет, название.
- **Mizu Focus** — режим без отвлечений:
  - панель инструментов и вкладки скрыты и появляются при наведении;
  - уведомления сайтов придерживаются;
  - по желанию — список запрещённых сайтов для пространства.
- **Быстрые действия** в адресной строке (всё считается локально):
  - команды через `>`: «> очистить cookies этого сайта», «> отключить звук всех вкладок»;
  - калькулятор и перевод единиц.

**Технические работы:** модель вкладок в `mizu-tabs` переходит на дерево; формат сеанса v2 с миграцией.

**Зависит от:** 0.2.0 (обновление нужно, чтобы безопасно выпускать миграции формата).

**Готово, когда:**
- сеанс из 300 вкладок восстанавливается быстрее секунды;
- миграция v1 → v2 проверена на настоящих профилях.

## 0.4.0 — «Глубокая вода»: приватность и данные

**Возможности**
- **Панель Mizu Shield v2:** разбивка по сайтам, хронология заблокированных запросов, отчёт об отпечатках.
- **Защита от отпечатков:** стандартные, но защитные значения для API с высокой энтропией (шум при чтении canvas/audio,
  округление `navigator.hardwareConcurrency`) через скрипты начала документа. Анонимность мы не обещаем.
- **Управление cookies:** блокировка сторонних cookies везде или для отдельных сайтов; автоочистка cookies сайтов,
  которые вы не посещали N дней.
- **Импорт из других браузеров** (Chrome, Edge, Firefox, Opera, Brave, Vivaldi):
  - закладки, история, открытые вкладки, поисковые системы, настройки;
  - экран предпросмотра для выбора категорий;
  - пароли и cookies — только через официальные форматы экспорта (CSV/HTML). Mizu не расшифровывает чужие хранилища DPAPI.
- **Зашифрованная резервная копия** профиля с паролем пользователя (Argon2id + XChaCha20-Poly1305 из проверенных крейтов).

**Зависит от:** 0.3.0 (пространства тоже импортируются и копируются).

**Готово, когда:**
- импорт из каждого браузера проверен в обе стороны на тестовых данных;
- восстановление копии проверено побитно.

## 0.5.0 — «Прилив»: пароли и синхронизация

**Возможности**
- **Пароли v2:**
  - подтверждение Windows Hello перед показом или заполнением;
  - генератор паролей;
  - проверка утечек с k-анонимностью (с устройства уходят только префиксы хешей);
  - ключи доступа (passkeys), когда их поддерживает движок.
- **Mizu Sync (по желанию):** сквозное шифрование закладок, истории, вкладок, настроек и паролей между устройствами.
  Сервер хранит только шифротекст; его можно развернуть у себя, код открыт под OSI-лицензией.

**Зависит от:** 0.4.0 (формат шифрования копий используется и для синхронизации).

**Готово, когда:** независимый аудит паролей и синхронизации не оставил открытых серьёзных замечаний.

## 0.6.0 — «Эстуарий»: встроенные инструменты

- **Просмотр PDF** с панелью в стиле Mizu поверх движка: пометки, заполнение форм, печать.
- **Переводчик:** перевод страниц локальной моделью, где позволяет железо. По умолчанию текст не уходит с устройства;
  облачный сервис — только с явного согласия.
- **Mizu Media:** общая панель всех вкладок со звуком и видео: пауза, звук, картинка в картинке, медиаклавиши Windows.
- **Инструменты разработчика:**
  - экспорт журнала сетевых запросов;
  - быстрые пресеты размеров экрана и устройств;
  - правила блокировки из DevTools прямо в Mizu Shield.
- Кнопки расширений на панели и их всплывающие окна, когда движок даст такой интерфейс.

## 0.7.0 — «Реки»: Linux, macOS и мобильные устройства

WebView2 есть только в Windows, поэтому на каждой платформе свой движок за интерфейсом `mizu-engine`:

| Платформа | Движок | Примечания |
|---|---|---|
| macOS | WKWebView | Системный движок с H.264/AAC; блокировка через правила WebKit плюс наш косметический слой и скриптлеты |
| Linux | WebKitGTK (или CEF) | WebKitGTK есть в дистрибутивах; CEF — только если там понадобятся расширения |
| Android | Android System WebView | Мобильный интерфейс вокруг того же HTML; Shield, пароли и скрипты — те же крейты |
| iOS / iPadOS | WKWebView | Apple требует WebKit на iOS (вне ЕС) |

- Уже переносимо: интерфейс (HTML/CSS/JS в `assets/ui`), хранилище, настройки, движок фильтров Mizu Shield, пароли
  (со связкой ключей платформы вместо DPAPI), скрипты и модель вкладок.
- Зависит от платформы: адаптер движка, окна и ввод, установщик и обновления.
- **Мобильной версии** нужна своя раскладка: адресная строка снизу, сетка вкладок, жесты. Настройки и возможности
  общие с десктопом.
- Расширения будут зависеть от движка. Расширения Chromium остаются прежде всего для Windows; на платформах с WebKit
  основные потребности закрывают скрипты и Shield.

**Готово, когда:** таблицы совместимости в ARCHITECTURE.md «зелёные» по основным возможностям на всех трёх платформах.

## 1.0.0 — «Океан»: стабильная версия

- Планка стабильности: не меньше 99,8% сеансов без сбоев по добровольной локальной статистике; нет известных ошибок
  с потерей данных.
- Пройден аудит доступности: только клавиатура, экранные дикторы, высокий контраст. При визуальном встраивании для
  этого нужен собственный провайдер UI Automation для содержимого страниц.
- Задокументированы версии и гарантии совместимости расширений и пользовательских скриптов.
- Выбрана долгосрочная стратегия движка (WebView2, CEF или Servo) с планом перехода.

## Идеи на рассмотрении

| Идея | Решение |
|---|---|
| **Движок Servo** | Следим. Это перспективный движок на Rust, но для ежедневной работы пока недостаточно совместим. Пересматриваем каждый выпуск. |
| **Встроенный криптокошелёк** | Нет. Вне задач браузера и расширяет поверхность атаки. |
| **ИИ-ассистент** | Только как необязательные локальные функции (пересказ, перевод). Никогда не включён по умолчанию и не отправляет содержимое страниц втихую. |
| **Режим чтения** | Да, около 0.6: просмотр для чтения с типографикой Mizu. |
| **Две вкладки рядом** | Да, около 0.3/0.4. Движок поддерживает несколько видимых представлений в окне. |
| **Больше языков интерфейса** | Да. Перевод — это один файл-словарь, помощь приветствуется. |
