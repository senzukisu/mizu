# Тестирование Mizu

## Автоматические тесты

```bash
cargo test --workspace
```

| Крейт | Что проверяется |
|---|---|
| mizu-core | Адрес или поисковый запрос (IDN, порты, IP, запрет `javascript:`), адреса поиска, источники (origin), очистка имени профиля, реестр внутренних страниц |
| mizu-settings | Сохранение и загрузка, значения по умолчанию для неполных файлов, восстановление повреждённого файла, исправление неверных значений |
| mizu-storage | Миграции; история (запись, поиск, подсказки, удаление, очистка за период); закладки (папки, перемещение, циклы, защита корней); жизненный цикл загрузок; разрешения; сеанс; сохранённые логины; **восстановление из копии при повреждении** |
| mizu-tabs | Активация после закрытия, место повторного открытия, правила закреплённых вкладок, ограничения перетаскивания, дублирование, переключение и сочетания клавиш, снимки |
| mizu-privacy | Блокировка сторонних запросов, исключения, `$redirect`, `$removeparam`, белый список, косметические фильтры и скриптлеты, файлы hosts, встроенный список, загрузка только по HTTPS, проверка списков, безопасность путей |
| mizu-userscripts | Разбор метаданных; `@match`/`@include` (шаблоны, регулярные выражения, `.tld`); установка, обновление, включение и удаление; лимит хранилища; генерация и экранирование загрузчика; ссылки GitHub/Gist/GitLab/Greasy Fork; несколько скриптов в одном файле; расписание обновлений; правила сайтов |
| mizu-media | Проверка Media Foundation запускается и находит декодер H.264 |
| mizu-update | Проверка подписи, подделанный манифест, чужой ключ, хеш установщика, сравнение версий |
| mizu-ui | Разбор протокола и отказ от неизвестных команд, поиск вшитых файлов и защита от выхода за пределы пути |
| mizu-browser | Сочетания клавиш, аргументы запуска, подсказки адресной строки и поисковики по ключевому слову, разбор data URL, белый список, имена загружаемых файлов, разбор CRX, генерация токенов, DPAPI, импорт и экспорт паролей CSV (Chrome, Firefox, Bitwarden) |

Проверка синтаксиса UI-скриптов (нужен Node.js):

```bash
for f in assets/ui/chrome/*.js assets/ui/flyout/*.js assets/ui/pages/*.js assets/ui/shared/*.js; do node --check "$f" || exit 1; done
```

## Ручной чек-лист (перед каждым выпуском)

Используйте чистый профиль: `MIZU_USER_DATA=%TEMP%\mizu-test`.

1. **Запуск и закрытие.** Mizu запускается быстрее чем за 2 секунды. При нескольких открытых вкладках закрытие
   спрашивает подтверждение, а при следующем запуске вкладки возвращаются.
2. **Современные сайты.** Проверьте:
   - YouTube: видео играет в 1080p/4K, полноэкранный режим, нет рекламы перед роликом;
   - вход на GitHub, веб-версию Discord, Reddit, Google, Википедию;
   - трансляцию на Twitch, оформление заказа в интернет-магазине;
   - тяжёлое одностраничное приложение (Figma или Notion).
3. **JS, CSS и WebAssembly.** html5test.com, демо WebAssembly, примеры WebGL и WebGPU.
4. **Вкладки.** Откройте 30 вкладок и проверьте: перетаскивание, закрепление, дублирование, отключение звука,
   закрытие средней кнопкой, возврат через Ctrl+Shift+T, Ctrl+1…9 и Ctrl+Tab.
5. **Сеанс и сбой.** Завершите процесс (`taskkill /IM mizu.exe /F`), запустите снова и проверьте, что вкладки вернулись
   (или появилась кнопка восстановления).
6. **История.** Поиск, удаление записи, очистка за последний час.
7. **Закладки.** Ctrl+D, переименование, перенос в папку, перетаскивание на странице закладок, панель закладок.
8. **Загрузки.** На большом файле проверьте:
   - паузу, продолжение, отмену и повтор;
   - «Открыть» и «Показать в папке»;
   - смену папки и вопрос «куда сохранить».
9. **Темы.** Светлая, тёмная и системная, все палитры, акцентный цвет, плотность и стиль. После перезапуска они сохраняются.
10. **Настройки сохраняются** после перезапуска.
11. **Приватное окно.**
    - Записей в истории нет.
    - Cookies не общие с обычными окнами.
    - После закрытия последнего приватного окна вы вышли из сайтов, на которые входили в нём.
12. **Очистка данных.** Очистите cookies «за последний час» и проверьте, что вы вышли из аккаунтов.
13. **Shield.** `https://d3ward.github.io/toolz/adblock` или похожая тестовая страница, переключатель для сайта, своё
    правило, добавление списка.
14. **Медиа.** В `mizu://media` у H.264/VP9/AV1 на подходящих видеокартах стоит «Аппаратно», звук играет.
15. **Песочница.** Process Explorer показывает процессы рендеринга с уровнем целостности untrusted/low.
16. **Защита внутренних страниц.** В консоли DevTools сайта `location = 'mizu://settings/'` ничего не делает.
17. **Память.** С 20 открытыми вкладками после задержки сна фоновые вкладки засыпают (диспетчер задач, Shift+Esc).
18. **Скрипты.** Установите скрипт с greasyfork.org и проверьте:
    - что он работает;
    - что `GM_setValue` сохраняется между перезагрузками.

    Затем отключите и удалите его.
19. **Расширения.** Установите расширение кнопкой «Добавить в Mizu» в Chrome Web Store, откройте параметры, отключите и
    удалите его.
20. **Пароли.**
    1. Войдите на сайт и проверьте, что появилось предложение сохранить пароль.
    2. Выйдите и заполните логин по значку ключа.
    3. Экспортируйте CSV и импортируйте снова.
    4. Кнопка «Открыть менеджер паролей» в «Настройки» → «Безопасность» открывает страницу паролей.
21. **Сайты скриптов.** Откройте «Где работает» у скрипта, ограничьте его одним сайтом и проверьте, что он работает
    только там. Затем добавьте сайт в «Никогда не запускать на».
22. **Вертикальные вкладки.** Переключите расположение в «Настройки» → «Оформление» и проверьте:
    - изменение ширины и сворачивание панели;
    - что «Новая вкладка» остаётся под последней вкладкой.
23. **Картинка в картинке.** Наведите курсор на видео и нажмите PiP, затем попробуйте Alt+Shift+P.
24. **Язык.** Переключите на русский в «Настройки» → «Основные» и проверьте, что переведены все страницы и меню.
25. **Установщик и обновление.**
    1. Установите через MizuSetup в свою папку и запустите Mizu из меню «Пуск». Проводник при этом работает нормально.
    2. Проверьте, что Mizu есть в «Приложениях по умолчанию».
    3. Удалите Mizu через «Параметры» → «Приложения» и через двойной щелчок по `uninstall.exe`.
    4. Выпустите тестовую версию с номером выше и проверьте, что «Перезапустить и обновить» её ставит.
