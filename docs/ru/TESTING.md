## Автотесты

```bash
cargo test --workspace
```

```bash
node scripts/check-ui.mjs
```

```bash
cargo clippy --workspace --all-targets -- -D warnings
```

CI (`.github/workflows/ci.yml`) проверяет интерфейс на Linux, а clippy и тесты — на Windows.

| Крейт | Что проверяется |
|---|---|
| mizu-core | адрес или поиск (IDN, порты, IP, отказ от `javascript:`), адреса поиска, источники, имена профилей, внутренние страницы, калькулятор и пересчёт единиц |
| mizu-settings | сохранение и чтение, значения по умолчанию для неполных файлов, восстановление из повреждённого файла, исправление плохих значений |
| mizu-storage | миграции, история, закладки (папки, перемещения, циклы, защищённые корни), плитки и папки новой вкладки, загрузки, разрешения, сеанс, пароли, импорт из других браузеров, восстановление из копии |
| mizu-tabs | активация после закрытия, позиция при открытии закрытой, порядок закреплённых, правила перетаскивания, дублирование, перебор, группы, пространства, дерево, снимки |
| mizu-privacy | блокировка сторонних запросов, исключения, `$redirect`, `$removeparam`, список исключений, косметические фильтры для сайтов, общие и процедурные, скриптлеты, файлы hosts, проверка списков |
| mizu-userscripts | метаданные, `@match`/`@include`, установка/обновление/удаление, предел хранилища, экранирование загрузчика, переписывание ссылок, несколько скриптов в файле, расписание обновлений, правила сайтов |
| mizu-update | проверка подписи, подменённые манифесты, чужой ключ, хеш установщика, сравнение версий |
| mizu-ui | разбор протокола, отказ от неизвестных команд, поиск файлов, выход за пределы пути |
| mizu-browser | сочетания и разбор клавиш, аргументы запуска, подсказки адресной строки, очистка куки, ссылки на медиа, data-URL, разбор CRX, DPAPI, CSV паролей |
| mizu-media | проверка Media Foundation находит декодер H.264 |

## Посмотреть интерфейс без щелчков

Чтобы проверить изменение глазами, запустите Mizu с **тестовым профилем** и приведите его в нужное состояние файлами и
адресами, а не вводом:

1. `MIZU_USER_DATA=%TEMP%\mizu-test` — свежий одноразовый профиль.
2. До запуска запишите `Default\settings.toml` (например, `[appearance] tab_layout = "side"`,
   `[general] welcome_version = 3`, чтобы пропустить тур).
3. Для вкладок: запустите один раз, закройте и запишите сеанс в `Default\mizu.db` (таблица `session`, JSON с `tabs`,
   `groups`, `spaces`, `split`, `parent`).
4. Нужное состояние открывается адресом: `mizu://settings/#q=…`, `mizu://newtab/#customize`,
   `mizu://newtab/#folder=<id>`, `mizu://welcome/#2`.
5. Снимите окно (например, через `PrintWindow`) и остановите только тот процесс, который запустили.

## Проверка перед выпуском

Используйте свежий профиль. Отмечайте каждую строку.

### Запуск и вкладки

- [ ] Запуск меньше 2 с; следующий запуск восстанавливает вкладки; после `taskkill /IM mizu.exe /F` предлагает
  восстановить.
- [ ] Первый запуск нового профиля один раз показывает тур в отдельном окне; браузер открывается после него.
- [ ] Вкладки: перетаскивание, закрепление, дублирование, звук, закрытие колёсиком, Ctrl+Shift+T, Ctrl+1…9,
  Ctrl+Tab, **«Выгрузить вкладку»**.
- [ ] 30+ тяжёлых сайтов быстро подряд: окно отзывчиво, полоса прокручивается без дрожания.
- [ ] Вкладки сбоку: одна верхняя строка с кнопками окна; перетаскивание пустой панели двигает окно; изменение ширины
  и сворачивание; перетаскивание в сетку закреплённых и обратно.
- [ ] Дерево: ссылка, открытая в новой вкладке, встаёт под свою страницу; свернуть/развернуть; закрыть ветку.
- [ ] Группы: создать, переименовать, цвет, свернуть щелчком, меню правым щелчком.
- [ ] Пространства: создать, переключить (сверху и сбоку), перенести вкладку, удалить; восстанавливаются после
  перезапуска.
- [ ] Разделённый экран: открыть, перетащить разделитель, поменять местами, закрыть; восстанавливается после
  перезапуска.
- [ ] Приватное окно: без истории, свои куки, после закрытия выход из сайтов.

### Адресная строка и страницы

- [ ] Подсказки, ключ `@g`, калькулятор, `10 km in mi`, быстрые действия `>`, переход на вкладку.
- [ ] Поиск на странице: следующее/предыдущее, регистр, Esc.
- [ ] Закладки: Ctrl+D, папки, панель появляется с первой закладкой, меню правого щелчка.
- [ ] Новая вкладка: добавить, изменить, переставить плитки; папка из плитки, брошенной на другую; панель «Настроить».
- [ ] Поиск и очистка истории; загрузки: пауза/продолжить/повторить, **«Открыть с помощью…»**.
- [ ] Импорт из установленного браузера: панель закладок Mizu не меняется, если галочка не отмечена.

### Приватность и безопасность

- [ ] Shield: тестовая страница рекламы; выключатель для сайта; своё правило; общее правило `##.class`; правило
  `:has-text()`.
- [ ] Настройки сайта: куки, «Не выходить из аккаунта», «Забыть этот сайт», разрешения, сброс масштаба.
- [ ] Масштаб сайта запоминается и применяется при возвращении.
- [ ] Пароли: предложение сохранить после входа, заполнение по ключу, импорт/экспорт CSV.
- [ ] Поисковые подсказки никогда не появляются в приватном окне.
- [ ] В консоли DevTools сайта `location = 'mizu://settings/'` ничего не делает.
- [ ] Ссылка на программу (например, `mailto:`) сначала спрашивает.

### Медиа

- [ ] YouTube 1080p/4K, полный экран, без рекламы перед роликом; трансляция Twitch.
- [ ] `mizu://media`: H.264/VP9/AV1 «Аппаратно» на подходящих видеокартах.
- [ ] Панель медиа: пауза/вперёд, громкость сайта, медиаклавиши, «Только один звук».
- [ ] Картинка в картинке: кнопка, Alt+Shift+P, кнопки следующего/предыдущего и перемотки.
- [ ] Если установлен VLC или mpv: правый щелчок по видео → **«Открыть видео в …»**.

### Скрипты, расширения, сочетания

- [ ] Установить скрипт с Greasy Fork; `GM_setValue` сохраняется; **«Где работает»** ограничивает его.
- [ ] Установить расширение через **«Добавить в Mizu»**; настройки переживают перезапуск; выключить и удалить.
- [ ] «Настройки» → «Сочетания клавиш»: изменить «Новая вкладка»; новые клавиши работают, старые нет; сбросить.

### Установка и обновление

- [ ] MizuSetup в свою папку: пункт в «Пуске», Mizu в «Приложениях по умолчанию», `uninstall.exe` удаляет его.
- [ ] Установленная копия видит более новую версию: «Обновить сейчас / Позже»; «Обновить сейчас» перезапускает в
  неё с вкладками.
- [ ] Откат: запустите `MizuSetup-X.Y.Z.exe /S --relaunch` с `MIZU_TEST_FAIL_START=1` — установщик вернёт
  `mizu.prev` и оставит `update-failed`; следующий обычный запуск сообщит, что обновление откатилось.
