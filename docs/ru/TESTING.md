# Тестирование Mizu

## Автоматические тесты

```bash
cargo test --workspace
```

| Крейт | Что проверяется |
|---|---|
| mizu-core | Адрес или поиск (IDN, порты, IP, запрет `javascript:`), адреса поиска, источники, имена профилей, внутренние страницы |
| mizu-settings | Сохранение и загрузка, значения по умолчанию для неполных файлов, восстановление повреждённого файла, исправление неверных значений |
| mizu-storage | Миграции, история, закладки (папки, перемещение, циклы, защита корней), загрузки, разрешения, сеанс, логины, **восстановление из копии** |
| mizu-tabs | Активация после закрытия, место повторного открытия, порядок закреплённых, ограничения перетаскивания, дублирование, переключение, снимки |
| mizu-privacy | Сторонние запросы, исключения, `$redirect`, `$removeparam`, белый список, косметика, скриптлеты, hosts, загрузка только по HTTPS, проверка списков |
| mizu-userscripts | Метаданные, `@match`/`@include`, установка, обновление и удаление, лимит хранилища, экранирование загрузчика, ссылки GitHub/Gist/GitLab/Greasy Fork, несколько скриптов в файле, расписание обновлений, правила сайтов |
| mizu-update | Проверка подписи, подделанный манифест, чужой ключ, хеш установщика, сравнение версий |
| mizu-ui | Разбор протокола, отказ от неизвестных команд, поиск вшитых файлов, защита путей |
| mizu-browser | Сочетания клавиш и разбор клавиш, аргументы запуска, подсказки адресной строки и поисковой системы, data URL, разбор CRX и ключи магазина, DPAPI, импорт и экспорт паролей CSV |
| mizu-media | Проверка Media Foundation находит декодер H.264 |

Проверка синтаксиса UI-скриптов (нужен Node.js):

```bash
for f in assets/ui/*/*.js; do node --check "$f" || exit 1; done
```

Линтер:

```bash
cargo clippy --workspace
```

## Ручной чек-лист

Проходите перед каждым выпуском на чистом профиле (`MIZU_USER_DATA=%TEMP%\mizu-test`).

### Запуск, вкладки и окна
- [ ] Mizu запускается быстрее 2 секунд и развёрнутым; при следующем запуске вкладки возвращаются; после
  `taskkill /IM mizu.exe /F` предлагается их восстановить.
- [ ] Вкладки:
  - перетаскивание, закрепление, дублирование, отключение звука, закрытие средней кнопкой;
  - Ctrl+Shift+T, Ctrl+1…9, Ctrl+Tab;
  - **«Выгрузить вкладку»** и **«Выгрузить остальные вкладки»** (при открытии вкладка загружается снова).
- [ ] Быстро откройте 30+ тяжёлых сайтов:
  - окно отвечает, Проводник не страдает;
  - полоса прокручивается вбок без дёрганья;
  - закрытие проходит плавно.
- [ ] Вертикальные вкладки («Настройки» → «Внешний вид»):
  - одна строка сверху с кнопками окна;
  - перетаскивание пустого места панели двигает окно;
  - боковая панель меняет ширину и сворачивается;
  - «Новая вкладка» остаётся под последней вкладкой.
- [ ] Меню и панели: повторный щелчок по их кнопке закрывает их.
- [ ] Приватное окно: истории нет, cookies отдельные, после закрытия последнего вы вышли из сайтов.

### Сайты и медиа
- [ ] YouTube (1080p/4K, полный экран, без рекламы перед роликом), вход на GitHub, Discord, Reddit, трансляция Twitch,
  оформление заказа, Figma или Notion.
- [ ] html5test.com, демо WebAssembly, примеры WebGL и WebGPU.
- [ ] `mizu://media`: у H.264/VP9/AV1 на подходящих видеокартах — «Аппаратно».
- [ ] «Картинка в картинке» на YouTube:
  - работают кнопка при наведении и Alt+Shift+P;
  - в плавающем окне работают «предыдущее/следующее» и перемотка на 10 секунд;
  - настройки положения кнопки и компактной кнопки применяются.
- [ ] Перетащите файл из Проводника в поле загрузки на странице.

### Данные
- [ ] История: поиск, удаление записи, очистка за последний час.
- [ ] Закладки:
  - Ctrl+D, переименование, перенос в папку;
  - панель появляется с первой закладкой;
  - правый щелчок → «Открыть в новой вкладке» / «Удалить».
- [ ] Загрузки: пауза, продолжение, отмена, повтор, открыть, показать в папке, смена папки, вопрос «куда сохранить».
- [ ] Настройки, темы, палитры и язык сохраняются после перезапуска.
- [ ] Очистите cookies «за последний час» и проверьте, что вы вышли из аккаунтов.

### Приватность и безопасность
- [ ] Shield: тестовая страница блокировщика, переключатель для сайта, своё правило, добавление списка.
- [ ] Пароли:
  - после входа появляется предложение сохранить, заполнение по значку ключа работает;
  - экспорт и импорт CSV;
  - «Настройки» → «Безопасность» → «Открыть менеджер паролей».
- [ ] Поисковые подсказки появляются при наборе и никогда — в приватном окне.
- [ ] В консоли DevTools сайта `location = 'mizu://settings/'` ничего не делает.
- [ ] Process Explorer показывает рендереры с уровнем целостности untrusted/low.

### Скрипты, расширения, сочетания клавиш
- [ ] Установите скрипт с greasyfork.org:
  - `GM_setValue` сохраняется между перезагрузками;
  - ограничьте его одним сайтом в **«Где работает»**, затем добавьте сайт в **«Никогда не запускать на»**.
- [ ] Установите расширение кнопкой «Добавить в Mizu»:
  - измените параметр, перезапустите — параметр сохранился;
  - отключите его, затем удалите.
- [ ] «Настройки» → «Сочетания клавиш»: измените «Новая вкладка»; новые клавиши работают, старые — нет; сбросьте.

### Установка и обновление
- [ ] MizuSetup в свою папку:
  - Mizu запускается из меню «Пуск»;
  - он есть в «Приложениях по умолчанию»;
  - `uninstall.exe` его удаляет.
- [ ] Выпустите тестовую версию с номером выше. Установленная копия спрашивает «Обновить сейчас / Позже», и
  «Обновить сейчас» перезапускает её в новой версии.
