## Быстрый старт

1. **Установите** `MizuSetup-x.y.z.exe` из [последнего выпуска](https://github.com/senzukisu/mizu/releases/latest).
   Права администратора не нужны.
2. **Приветствие.** При первом запуске Mizu покажет короткий тур. В нём можно сделать Mizu браузером по умолчанию и
   импортировать данные из другого браузера. Оба шага можно сделать и позже в **«Настройки» → «Основные»**.
3. **Пять вещей, которые стоит знать:**
   - **Ctrl+T** — новая вкладка, **Ctrl+W** — закрыть, **Ctrl+Shift+T** — вернуть последнюю закрытую.
   - **Ctrl+L** — в адресную строку. Наберите там `>`, чтобы увидеть быстрые действия.
   - **Щит** в адресной строке блокирует рекламу. Если сайт сломался, нажмите на щит и выключите Shield для сайта.
   - **Замок** в адресной строке открывает настройки сайта: куки, разрешения, «Не выходить из аккаунта».
   - В **Меню (⋮) → «Настройки»** есть поиск: просто наберите, что ищете.
4. Хотите вкладки сбоку? **«Настройки» → «Вкладки» → «Расположение вкладок» → «Сбоку».**

## Вкладки

### Основы

| Действие | Как |
|---|---|
| Новая / закрыть вкладку | **Ctrl+T** / **Ctrl+W** или щелчок колёсиком по вкладке |
| Вернуть закрытую вкладку | **Ctrl+Shift+T** (помнятся последние 25) |
| Следующая / предыдущая | **Ctrl+Tab** / **Ctrl+Shift+Tab**; **Ctrl+1…8** по номеру, **Ctrl+9** — последняя |
| Переставить | перетащить вкладку |
| Закрепить, дублировать, выключить звук, закрыть остальные | правый щелчок по вкладке |
| Много вкладок | полоса прокручивается вбок (колёсиком или тачпадом), активная вкладка всегда видна |

### Спящие и выгруженные вкладки

- **«Выгрузить вкладку»** (правый щелчок) закрывает страницу и освобождает память; вкладка остаётся и загрузится
  снова, когда вы её откроете. **«Выгрузить остальные вкладки»** — то же для всех остальных. Вкладки со звуком не
  трогаются.
- **Спящие вкладки** («Настройки» → «Производительность»): фоновые вкладки, которыми вы давно не пользовались, усыпляются сами.
- **Режим эффективности** («Настройки» → «Производительность»): простаивающие вкладки через две минуты расходуют
  меньше памяти.

### Вкладки сбоку и закреплённые сайты

«Настройки» → «Вкладки» → **«Расположение вкладок» → «Сбоку»**. Сверху остаётся одна строка: навигация, адресная
строка, меню и кнопки окна.

- Ширина боковой панели меняется перетаскиванием края; двойной щелчок по краю возвращает стандартную. Стрелка внизу
  сворачивает панель до значков.
- **Закреплённые сайты** — сетка значков наверху. Перетащите вкладку на сетку, чтобы закрепить, и обратно в список,
  чтобы открепить.
- Закреплённый сайт помнит свою страницу. Если уйти на другой сайт, значок получит пунктирную рамку; правый щелчок →
  **«Вернуться на закреплённую страницу»** или **«Закрепить эту страницу вместо неё»**.

### Дерево вкладок

Когда вкладки сбоку, вкладка, открытая со страницы (по ссылке, Ctrl+щелчком), встаёт **под** неё с отступом.

- Стрелка рядом с вкладкой сворачивает и разворачивает открытые из неё вкладки.
- Правый щелчок → **«Закрыть вкладку и открытые из неё»** закрывает всю ветку.
- При закрытии вкладки её «дети» поднимаются на уровень выше.
- Выключить: «Настройки» → «Вкладки» → **«Дерево вкладок»**.

### Группы вкладок

- Правый щелчок по вкладке → **«Добавить в новую группу»** (или в существующую).
- **Щелчок** по метке группы сворачивает или разворачивает её; **правый щелчок** — название, цвет, разгруппировать
  или закрыть вкладки группы.
- Перетащите вкладку между вкладками группы, чтобы добавить, или из группы, чтобы убрать.

### Пространства

Отдельные наборы вкладок в одном окне — например, *Работа* и *Музыка*. Видны только вкладки текущего пространства.

- **Создать:** Меню → **«Новое пространство»** или правый щелчок по вкладке → **«В новое пространство»**.
- **Переключить:** кнопки внизу боковых вкладок или кнопка пространства в начале полосы вкладок (появляется, когда
  пространств два и больше). Каждое пространство помнит свою последнюю вкладку.
- **Изменить:** щелчок по кнопке текущего пространства (или правый щелчок по любой) — название, цвет и значок,
  новое пространство или удаление. При удалении вкладки переходят в предыдущее пространство.
- **Перенести вкладку:** правый щелчок по ней → **«Переместить в …»**.
- «Закрыть другие вкладки», Ctrl+Tab и Ctrl+1…9 работают в пределах текущего пространства.

### Разделённый экран

Две вкладки рядом в одном окне.

- Правый щелчок по вкладке → **«Открыть рядом (разделённый экран)»** — она встанет рядом с текущей; или правый
  щелчок по текущей → **«Разделить с новой вкладкой»**.
- Размер половин меняется перетаскиванием разделителя. Щелчок в половину делает её активной вкладкой.
- Правый щелчок по любой из двух → **«Поменять местами»** или **«Закрыть разделённый экран»**.

### Сеансы

- Mizu открывает ваши вкладки при запуске («Настройки» → «Основные» → **«При запуске»**). Восстановленные вкладки
  загружаются, когда вы на них щёлкаете.
- С **«Продолжить с того же места»** сайты не выходят из аккаунтов: Mizu хранит их сеансовые куки, зашифрованные
  вашей учётной записью Windows.
- После сбоя Mizu предложит восстановить сеанс.
- Группы, пространства, разделённый экран и дерево вкладок восстанавливаются тоже.

### Приватные окна

**Ctrl+Shift+N.** Ничего не попадает в историю, куки отдельные от обычных окон, и всё стирается, когда закрывается
последнее приватное окно. Расширения там не работают.

## Адресная строка

| Наберите… | Получите |
|---|---|
| адрес или слова | страницу или поиск; **Enter** открывает первую подсказку |
| часть названия открытой вкладки | **«Перейти на вкладку»** (и в других окнах) |
| `@g rust`, `@w вода`, `@gh mizu` | один поиск в Google, Википедии, GitHub (свои ключевые слова — в «Настройки» → «Поиск») |
| `2+2*3`, `(1,5+2)^2`, `15% * 80` | ответ; **Enter** копирует его |
| `10 km in mi`, `70 f to c`, `1,5 gb in mb` | пересчитанное значение; **Enter** копирует |
| `>` | быстрые действия: очистить данные сайта, выключить звук везде, выгрузить или закрыть остальные вкладки, новая группа, приватное окно, страницы Mizu… Слова сужают список |

- **Подсказки** берутся из истории, закладок и страниц Mizu и считаются на вашем ПК. С включёнными **«Поисковыми
  подсказками»** («Настройки» → «Поиск») подсказывает и поисковик — для этого ему отправляется набранный текст, в
  приватных окнах никогда.
- **Поисковик по умолчанию:** «Настройки» → «Поиск» или кнопка с буквой на новой вкладке.
- **Поиск на странице:** **Ctrl+F**. **Enter / Shift+Enter** (или **F3 / Shift+F3**) — следующее / предыдущее,
  **Aa** — с учётом регистра, **Esc** — закрыть.
- Значки справа: **ключ** (сохранённые пароли для сайта), **звезда** (закладка), **щит** (сколько заблокировано).

## Закладки, новая вкладка, история, загрузки

### Импорт из другого браузера

«Настройки» → «Основные» → **«Импорт»** (или `mizu://import/`). Mizu покажет найденные профили: Chrome, Edge,
Яндекс, Brave, Vivaldi, Chromium, Opera, Opera GX и Firefox. Выберите, что перенести: закладки, историю, поисковики.

- Закладки попадают в папку **«Импорт из …»** в «Других закладках»; панель закладок другого браузера становится там
  подпапкой. Отметьте **«Ещё и добавить его панель на панель закладок Mizu»**, если хотите видеть их на панели.
- Пароли: экспортируйте CSV из другого браузера и импортируйте его в паролях Mizu.

### Закладки

- **Ctrl+D** или звезда сохраняет страницу в **«Другие закладки»**. Выберите другую папку в панели — новые закладки
  будут попадать туда.
- **Ctrl+Shift+O** — менеджер закладок: поиск, перестановка перетаскиванием, папки.
- **Панель закладок** показывает только то, что вы туда положили, и появляется с первой закладкой. **Ctrl+Shift+B**
  показывает или скрывает её. **«Другие закладки»** — в её правом конце.
- Правый щелчок по закладке на панели: открыть в новой вкладке, окне или приватном окне, скопировать ссылку, удалить.

### Новая вкладка

- **Плитки** — отдельный список, не связанный с закладками. **+** добавляет, карандаш изменяет, перетаскивание
  переставляет.
- **Папки:** бросьте плитку на **середину** другой — получится папка (на середину папки — добавить в неё, на край
  плитки — переставить). Щелчок по папке: название, добавить или переставить плитки, вынуть плитку. При удалении
  папки плитки остаются.
- **«Настроить»** (справа внизу): 13 фонов или своя картинка с ползунком затемнения; часы и приветствие (с вашим
  именем); размер плиток; счётчик Shield; виджеты — **«Сейчас играет»**, недавно закрытые вкладки, заметки.

### История

**Ctrl+H.** Поиск, удаление отдельных записей, очистка за последний час, день, неделю, месяц или за всё время.
«Настройки» → «Конфиденциальность» → **«Очищать при закрытии Mizu»** делает это автоматически.

### Загрузки

**Ctrl+J.** У каждой загрузки видны скорость и оставшееся время, её можно приостановить, продолжить или повторить.
Готовый файл: щелчок открывает, **«Открыть с помощью…»** — выбор программы. «Настройки» → «Загрузки» — папка или
вопрос «куда сохранить» каждый раз.

## Приватность и Mizu Shield

### Что отправляет Mizu

**Телеметрии нет.** Сам Mizu обращается только к серверам списков фильтров, адресам обновления скриптов, манифесту
обновлений на GitHub и — только если вы их включили — к подсказкам поисковика. Ваши данные лежат в
`%LOCALAPPDATA%\Onibi Lab\Mizu\User Data`.

### Mizu Shield

Блокирует рекламу, трекеры и известные вредоносные сайты по спискам фильтров, совместимым с uBlock Origin.

- **Щит** в адресной строке показывает, сколько запросов заблокировано. Щелчок — выключить Shield для сайта.
- «Настройки» → **«Mizu Shield»**:
  - **Списки фильтров:** включайте и выключайте списки (Annoyances и EasyList Cookie выключены по умолчанию) или
    добавьте любой список по HTTPS-адресу. Списки обновляются сами; **«Обновить списки»** — прямо сейчас.
  - **Мои правила:** свои правила в синтаксисе uBlock, например `example.com##.cookie-banner` или `||ads.example^`.
- Что понимает Shield: сетевые правила, `$redirect`, `$removeparam`, скриптлеты и скрытие элементов — правила для
  сайтов, общие правила (`##.ad-banner` на любом сайте) и процедурные (`:has-text()`, `:upward()`, `:xpath()`,
  `:remove()`, `:style()` и другие), в том числе для содержимого, которое страница добавляет позже.
- `mizu://shield` — статистика.

### Настройки сайта

Замок → **«Настройки сайта»** (или `mizu://site/?host=example.com`):

- Shield для сайта вкл/выкл;
- его куки, **«Не выходить из аккаунта»** (сайт никогда не очищается), **«Забыть этот сайт»** (куки, хранилище,
  кеш);
- разрешения — камера, микрофон, местоположение, уведомления…: Разрешить / Блокировать / Спрашивать;
- запомненный для сайта масштаб с кнопкой **«Сбросить»**;
- последний визит.

### Куки

- **Сторонние куки** блокируются («Настройки» → «Конфиденциальность», нужен перезапуск). Выключайте это,
  только если перестал работать встроенный вход.
- **Отслеживание:** «Настройки» → «Конфиденциальность» — уровень защиты от отслеживания и **Global Privacy Control**.
- **Очистка куки:** забывать сайты, где вы не были 7, 30 или 90 дней, раз в день. Сайты с «Не выходить из аккаунта»
  остаются.
- **Очистить данные браузера:** **Ctrl+Shift+Delete**.

### Ссылки на программы

Когда сайт хочет открыть Steam, Telegram, Zoom, почтовую программу или другое приложение, Mizu сначала спросит.
**«Всегда разрешать»** запоминает выбор для сайта; «Настройки» → «Конфиденциальность» → **«Открытие
программ с сайтов»** показывает и удаляет такие разрешения.

### Отчёты о сбоях

Если Mizu упадёт, короткий отчёт сохранится **только на вашем ПК**. «О Mizu» показывает, сколько их, и открывает
папку; при желании приложите отчёт к issue на GitHub.

Подробнее: [Безопасность](SECURITY.md).

## Пароли

- **Сохранить:** после входа на сайт Mizu спросит, сохранить ли логин. **«Никогда для этого сайта»** — больше не
  спрашивать там.
- **Заполнить:** нажмите **ключ** в адресной строке и выберите логин.
- **Управлять:** «Настройки» → «Пароли и безопасность» → **«Открыть менеджер паролей»** (или `mizu://passwords`): поиск,
  показать, скопировать, изменить.
- **Импорт / экспорт:** CSV из Chrome, Edge, Firefox, Opera, Brave, Vivaldi или Bitwarden. Экспорт — это обычный
  текст, удалите файл после использования.
- Пароли зашифрованы вашей учётной записью Windows (DPAPI) и никогда не покидают ПК.

## Музыка и видео

### Панель медиа

Пока вкладка играет звук или видео, на панели появляется **кнопка музыки**. В её панели — все играющие вкладки с
треком и обложкой, назад / пауза / вперёд, громкость и **«Перейти на вкладку»**.

- Громкость запоминается для сайта («Настройки» → «Мультимедиа» показывает и сбрасывает).
- **«Только один звук»** («Настройки» → «Мультимедиа»): когда начинает играть одна вкладка, остальные встают на паузу.
- Медиаклавиши клавиатуры работают, пока Mizu в фокусе. Ещё: **Ctrl+Alt+Пробел** — пауза,
  **Ctrl+Alt+Вправо / Влево** — следующий / предыдущий трек.
- Новая вкладка может показывать **«Сейчас играет»** («Настроить» → «Виджеты»).

### Картинка в картинке

Наведите на видео и нажмите **PiP** или **Alt+Shift+P**. В плавающем окне есть кнопки предыдущего/следующего видео и
перемотки на 10 секунд. «Настройки» → «Мультимедиа»: кнопка вкл/выкл, её положение, компактная кнопка.

### Открыть в медиаплеере

Если установлен VLC, mpv, PotPlayer, MPC-HC или MPC-BE: правый щелчок по видео → **«Открыть видео в …»** или по
ссылке на видео или песню → **«Открыть ссылку в …»**. Страницы YouTube, Twitch, Vimeo и SoundCloud передаются как
страницы — для плееров, которые умеют их открывать. «Настройки» → «Мультимедиа» → **«Медиаплеер»** — выбор плеера
или выключение.

### Кодеки

`mizu://media` показывает, какие форматы воспроизводятся и декодирует ли их видеокарта. Подробнее:
[Кодеки](CODECS.md).

## Скрипты и расширения

### Mizu Scripts (пользовательские скрипты)

Формат Tampermonkey/Greasemonkey. Меню → **«Скрипты и расширения»** (`mizu://scripts`).

- **Установить:** щёлкните ссылку `.user.js` на Greasy Fork или OpenUserJS, вставьте ссылки (GitHub, GitLab, Gist,
  Codeberg…; можно несколько сразу) или добавьте файлы. Перед подтверждением видно, что делает скрипт.
- **«Где работает»** (кнопка с глобусом): **«Только выбранных сайтах»** или **«Никогда не запускать на»**.
  `youtube.com` — весь сайт, `github.com/user` — один раздел. После изменения обновите открытые страницы.
- **Обновления:** проверяются раз в день; **«Проверить обновления»** — сейчас.

### Расширения

- В **Chrome Web Store** нажмите **«Добавить в Mizu»** на странице расширения. Или установите файл `.crx`/`.zip` или
  распакованную папку («Скрипты и расширения» → «Расширения»).
- Только расширения Chromium **Manifest V3**; дополнения Firefox не поддерживаются. Кнопок расширений на панели пока
  нет: их страницы открываются во вкладке. В приватных окнах расширения не работают.

## Под себя

- **«Настройки» → «Внешний вид»:** светлая, тёмная или системная тема; палитры и любой акцентный цвет (можно
  подкрасить им окно); плотность; стиль «Мягкий», «Круглый» или «Чёткий»; полупрозрачность Mica (Windows 11); шрифт
  интерфейса; анимации; кнопки панели; расположение вкладок.
- **Масштаб:** **Ctrl+плюс / минус**, **Ctrl+колесо**, **Ctrl+0** — сброс. Mizu запоминает масштаб **для каждого
  сайта**; сбросить — замок → «Настройки сайта». Масштаб по умолчанию — в «Настройки» → «Внешний вид».
- **Язык:** «Настройки» → «Основные» → «Язык»: «Автоматически» (как в Windows), English или «Русский». После
  перезапуска применится везде.
- **Настройки, которым нужен перезапуск,** показывают кнопку **«Перезапустить Mizu»**; вкладки вернутся.
- **Скорость** («Настройки» → «Производительность»): **«Подключаться, пока я набираю»** открывает соединение с
  набираемым сайтом ещё до Enter; **«Загружать закреплённые вкладки после запуска»** готовит закреплённые сайты в
  фоне. Полоса загрузки под адресной строкой показывает настоящий ход загрузки страницы.

### Экспериментальные функции

«Настройки» → **«Экспериментальное»**: функции, которые мы пробуем, — они могут измениться или исчезнуть, а
выключение возвращает всё как было.

- **Тёмный режим для всех сайтов** — движок затемняет светлые страницы (перезапуск).
- **Тонкие полосы прокрутки** — узкие, как в Windows 11 (перезапуск).
- **Параллельная загрузка** — большие файлы в несколько соединений (перезапуск).
- **Двойной щелчок закрывает вкладку** и **колесо мыши переключает вкладки** (с вкладками сбоку — с Shift).

## Обновления

- **«Настройки» → «Основные» → «Обновления» → «Обновлять Mizu автоматически»:** Mizu проверяет вскоре после запуска
  и раз в несколько часов, скачивает и проверяет обновление, затем спрашивает **«Обновить сейчас» / «Позже»**.
  «Обновить сейчас» перезапускает Mizu вместе с вкладками.
- **«Проверить обновления»** — проверить сразу.
- **Канал обновлений:** «Стабильный» или **«Бета»** (новые версии раньше, для проверки).
- **Если обновление не запустится,** Mizu сам вернётся к предыдущей версии и сообщит об этом; эту версию он больше не
  предложит.
- **Портативная** копия сама не обновляется: она сообщает о новой версии.
- Веб-движок (WebView2) обновляет Windows.

## Сочетания клавиш

Любое действие меняется в **«Настройки» → «Сочетания клавиш»**: нажмите карандаш и затем новые клавиши (Esc —
отмена). Если клавиши были у другого действия, они перейдут к новому. Стрелка сбрасывает одно действие, **«Сбросить
все сочетания»** — все.

| Вкладки и окна | |
|---|---|
| Новая вкладка | Ctrl+T |
| Закрыть вкладку | Ctrl+W, Ctrl+F4 |
| Открыть закрытую вкладку | Ctrl+Shift+T |
| Следующая / предыдущая вкладка | Ctrl+Tab, Ctrl+PgDn / Ctrl+Shift+Tab, Ctrl+PgUp |
| Вкладка 1…8 / последняя | Ctrl+1…8 / Ctrl+9 |
| Новое окно | Ctrl+N |
| Новое приватное окно | Ctrl+Shift+N, Ctrl+Shift+P |
| Полный экран | F11 |

| Страницы | |
|---|---|
| Адресная строка | Ctrl+L, Alt+D, F6, Ctrl+K, Ctrl+E |
| Назад / вперёд | Alt+Влево / Alt+Вправо |
| Домашняя страница | Alt+Home |
| Обновить / без кеша | F5, Ctrl+R / Ctrl+F5, Shift+F5, Ctrl+Shift+R |
| Поиск на странице / следующее / предыдущее | Ctrl+F / F3, Ctrl+G / Shift+F3, Ctrl+Shift+G |
| Увеличить / уменьшить / сбросить масштаб | Ctrl+плюс / Ctrl+минус / Ctrl+0 |
| Печать | Ctrl+P |
| Картинка в картинке | Alt+Shift+P |

| Mizu | |
|---|---|
| Добавить страницу в закладки | Ctrl+D |
| Показать или скрыть панель закладок | Ctrl+Shift+B |
| Закладки / История / Загрузки | Ctrl+Shift+O / Ctrl+H / Ctrl+J |
| Очистить данные браузера | Ctrl+Shift+Delete |
| Пауза / следующий / предыдущий трек | Ctrl+Alt+Пробел / Ctrl+Alt+Вправо / Ctrl+Alt+Влево |

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Сайт выглядит сломанным | Нажмите на щит и выключите Shield для сайта. Если помогло, сообщите о сайте авторам списка фильтров. |
| Сайт всё время выкидывает из аккаунта | Замок → «Настройки сайта» → **«Не выходить из аккаунта»**. Если вход встроенный, попробуйте разрешить сторонние куки («Настройки» → «Конфиденциальность»). |
| Видео подтормаживает | Откройте `mizu://media`. Если у кодека не «Аппаратно», обновите драйвер видеокарты; для HEVC установите «Расширения для видео HEVC». |
| Медленно со множеством вкладок | Правый щелчок по вкладке → **«Выгрузить остальные вкладки»**; не выключайте спящие вкладки («Настройки» → «Производительность»). |
| Сочетание клавиш не работает | «Настройки» → «Сочетания клавиш»: клавиши могли перейти к другому действию. Если сомневаетесь — **«Сбросить все»**. |
| Нет поисковых подсказок | «Настройки» → «Поиск» → **«Поисковые подсказки»** должны быть включены; в приватных окнах их нет; у некоторых поисковиков их нет вовсе. |
| На панели закладок то, чего я не добавлял | Правый щелчок → «Удалить» или скройте панель сочетанием Ctrl+Shift+B. |
| Нет пункта «Открыть видео в …» | Поддерживаемый плеер не найден или выключен: «Настройки» → «Мультимедиа» → «Медиаплеер». |
| «Нет среды выполнения WebView2» | Установите Microsoft Edge WebView2 Runtime с сайта Microsoft и запустите Mizu снова. |
| Что-то другое | Журналы лежат в `%LOCALAPPDATA%\Onibi Lab\Mizu\User Data\logs`. Приложите последний к [issue](https://github.com/senzukisu/mizu/issues). |
