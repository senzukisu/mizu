# Mizu — рабочий журнал

_Обновлено: 2026-11-10. Внутренний файл разработки; пользовательская документация — README и docs/._

## Состояние

Mizu 0.1.0 собирается, запускается и выпускается через `scripts/release.ps1`:
- `MizuSetup-0.1.0.exe` (установщик);
- портативный zip;
- подписанный `mizu-update.json` и `.sig`.

Сделано в 0.1.0:
- **Mizu Shield** — uBlock-совместимые списки, зеркала и повторы при загрузке.
- **Пароли** — DPAPI, красивое предложение сохранить, заполнение из адресной строки, импорт и экспорт CSV.
- **Mizu Scripts** — установка с GitHub и других площадок, несколько скриптов сразу, автообновление.
- **Расширения** — установка из Chrome Web Store.
- **Вертикальные вкладки** — меняют ширину, сворачиваются, «Новая вкладка» под последней вкладкой.
- **Интерфейс** — картинка в картинке, русский перевод, автообновление, установщик, окно открывается развёрнутым.

Проверено вживую:
- запуск за ~0,46 с (release);
- YouTube 4K без рекламы;
- русский интерфейс;
- установка расширения из магазина;
- страница «О Mizu».
